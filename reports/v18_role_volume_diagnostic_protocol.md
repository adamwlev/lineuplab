## Separating action volume from allocation and conversion

Use rows with jointly observed FGA, FTA and location labels. Print lost exposure
and keep the original all-row point comparison separately. Aggregate counts and
predicted expected counts to offensive-five×quarter, retaining player slots.
Average seed expected counts, not products of seed-mean rates. In particular
expected FTM is mean(FTA×FT make probability) across seeds.

Factor field-goal points into total FGA × player attempt shares × each player's
location distribution × location-conditioned conversion, valued at2/3points.
Replace predicted factors with realized factors, in this fixed order:
team volume, actor shares, location, conversion. A component is points before
minus after its replacement. For FT points use volume, actor shares, conversion.
Report the reversed replacement order as a sensitivity, not a second winner.
Zero observed attempts retain predicted conditional proportions/conversion;
zero total attempts nullify the downstream product. No invented observed rate.

Add the observed event-ledger minus recorded-points discrepancy and the saved
direct calibration shift, so components exactly reconstruct calibrated error
on the same valid-label rows. FGA/FTA already include renewal: do not add rebounds
or turnovers a second time as point bonuses/penalties. Turnovers get their own
count/share errors, not an arbitrary extra point component. Aggregation loses
within-cell context variation; the exact factorization is of aggregate counts,
not a new neural intervention or identified causal explanation.

Report weighted signed and absolute component means and the RMSE obtained by
subtracting each component from calibrated predictions. Those substitutions
use future realized outcomes: oracle diagnostics, not attainable gains or
deployable corrections. Preserve both forward/reverse results and all cells.

## Role-change library

One observed player×quarter record per active offensive player. Compare the
outer quarter with the immediately preceding365calendar days, strictly before
the origin. Use the same joint-observed-label exposure for numerator and
denominator. Record all players, but mark a role comparison supported only if
both periods have at least300valid on-court possessions, five distinct games
and50player FGA. This support rule defines a diagnostic, never a product gate.

Measure shares among the player's on-floor team events, not share of total
team minutes: FGA, FTA, turnovers, and FGA+.44FTA+TO opportunity mass. Measure
three-point attempt fraction and rim-bin attempt fraction separately. These
are observable shot/opportunity proxies, not ball handling or true creation.

Fixed large-change labels: absolute FGA-share shift>=5percentage points;
opportunity-share shift>=5pp; three-point fraction or rim fraction shift>=15pp.
Labels may overlap. Keep signed changes and all eligible nonchanges, not just
top changes. Location labels require the same50attempt support. FTA/TO shares
remain continuous descriptors because low event counts make threshold labels
unreliable. Compute five-player forecast shares from the saved role exports on
exactly the same current rows. Compare each model with the strictly prior
observed share as an unchanged-role baseline. Population metrics weight players
by their valid on-court possessions; this repeats each team possession five
times for player estimands, never for lineup point metrics.

Attach names from archived metadata only. No invented names or current rosters.
Link player changes back to current broad lineup cells and the unchanged
transfer registry. Report lineup errors and candidate-specific existing finite
interval coverage for cells containing>=1supported large FGA-share changer;
count such cells once. This slice is outcome-defined and cannot establish
prospective superiority or new interval calibration.

Add a distinct prefix-only context descriptor for each supplied five/player:
fraction of prior365-day teammate exposure assigned to the four supplied
teammates (0–1). It uses only pre-origin appearances and the proposed lineup
identities; it does not certify an available roster, an injury, or a transaction
known beforehand. Report it continuously. Team-change membership is separately
the existing retrospective registry, not proof that within-team changes are
caused by injuries. New injury/transaction verification is out of scope.

## Verification and stopping

Tests cover exact forward/reverse identities, empty bins, unequal player shares,
seed FTM averaging, strict prior dates, support boundaries and unique lineup
membership. Verify original receipt hashes and exact row/ID joins. Use a new
versioned output directory and durable verbose log. Log progress per origin.
Stop after all44quarters, tables, named case library, integrity checks and
documented interpretation. No added arm, threshold search, trained correction
or full run follows automatically. All three standards retain equal standing;
these observational diagnostics cannot validate synthetic lineup quality.
