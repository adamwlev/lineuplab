## Hosting

- **Choice.** An assets-only Cloudflare Worker serves the site, and Cloudflare Registrar holds
  the domain:
  - Cloudflare's docs say static asset requests are "free and unlimited", which matters at
    about 14 MB a visit;
  - the per-file limit is 25 MiB, and the largest file, players.txt, is 12.7 MB;
  - the cost is the domain alone.
- **Domains** (registry lookups, 2026-10-19):
  - available: lineuplab.dev, anyfive.app, getlineuplab.com and a few others;
  - taken: lineuplab.com, .app, .org, .net, .io, .co and .ai.
- **Build.** `tool/build_lineups.py --site --out DIR` writes the standalone site:
  - `index.html` as a whole document: the doctype and base styles that the artifact host's
    frame used to supply;
  - a description and a link preview (`tool/preview.png`, 1200×630);
  - an icon (`tool/favicon.svg`).
- **Checks run in standards mode now.** The 34 page checks pass on this build
  (`node scripts/page_check.mjs DIR index.html`). Until now the checks and the persona
  sessions had loaded the bare fragment, which browsers render in quirks mode.
- **Deploy.** `npx wrangler@4 deploy --config tool/wrangler.jsonc --assets DIR`:
  - the Worker is `lineuplab`, serving lineuplab.dev and www.lineuplab.dev;
  - Wrangler signed in to Adam's account with `wrangler login --device`, which works while
    Adam is remote: he approves a code on his phone, and no credential passes through the
    conversation. He can revoke it in the dashboard.
- **Verified live** (version 35f470a8, from `paths.CLEAN/site_2026_10_19_github`):
  - every file matches the build byte for byte;
  - a first visit downloads 13.7 MB (brotli);
  - on an emulated phone the page forecasts the default five as the build does (net +2.1,
    80% range −3.7 to +7.8), with no page errors;
  - `model.html` redirects to `/model`, keeping its anchors.
- **A correction.** Before measuring, I told Adam that serving raw binary instead of base64
  would save about 25%. With compression it saves about 10%, so the files stay base64 text.

## Open source

- **Audit of this repository:**
  - the old database password is in 17 commits of history (the current tree has it redacted);
  - scraped-data caches up to 695 MB are in history, and GitHub refuses files over 100 MB;
  - every commit carries a usc.edu email.

  So the public repository is a fresh history, and this one stays private.
- **What stays private** (`scripts/publish_repo.sh`, which copies HEAD minus these):
  - the downloader `lineups/ingest.py` and its test;
  - `scripts/rescrape_pages.py`, `scripts/rescrape_pilot.py` and `scripts/after_download.sh`;
  - the golden test fixtures, which hold labelled rows from five 2020 games;
  - `tool/five.html`, the retired page, which embeds its player data.

  This keeps the promise in the request to Sports Reference: no data and no download scripts.
- **The parser split.** The page parsers moved, unchanged, from `lineups/ingest.py` to
  `lineups/bref_pages.py`, so that only the downloading code stays private. `ingest`
  re-exports them for the private scripts. All 124 tests pass.
- **First public commit:** 753f774 (from 445d496b), 499 files, 2.4 MB of history, under
  Adam's GitHub noreply address. The script refuses to publish if it finds a password
  assignment, a private key or a token. GitHub detects the MIT licence.
- **Updating it:** run `scripts/publish_repo.sh ../lineuplab "message"`, read the commit, then
  `git -C ../lineuplab push` with Adam's go-ahead.

## Sports Reference

- **What their terms say** (Terms of Use, updated 2023-05-19; data use page; read 2026-10-19):
  - sharing data from their pages is "welcomed, whether for commercial or non-commercial
    purposes", with credit to Sports Reference;
  - the prohibitions still apply, among them using content "for purposes of training,
    fine-tuning, prompting, or instructing artificial intelligence models", including
    machine learning that predicts or scores inputs;
  - the data use page says "you should not create websites or tools based on data you scrape
    from Sports Reference."
- **The request.** Adam sent a permission request through their feedback form on 2026-10-19.
  It describes the site:
  - free, with no ads or accounts;
  - credited, with a link;
  - showing no raw tables;
  - with open-source code that holds no data and no download scripts.

  It also asks to download 2026–27 games under their rate limit.
- **Why it matters for v2:** the 2026–27 data refresh and the scoring of the frozen
  prospective record both depend on downloading from them.
